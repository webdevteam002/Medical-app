# Admin Panel (Next.js)

Admin dashboard for content upload, question bank, exams, user management.

## Planned pages

- `/login`
- `/dashboard`
- `/users`
- `/content/years`, `/content/subjects`, `/content/materials`
- `/questions`
- `/exams`
- `/subscriptions`

## Setup (Phase 1)

```bash
npm install
cp .env.example .env.local
npm run dev
```
