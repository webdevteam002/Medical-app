# Person 3 — Desktop Design & Content Guide

**Role:** Content Lead + UX Polish
**Goal:** Optimize the study content and UX for students using large screens, mice, and keyboards.

---

## 1. Desktop UX Audit

When Person 2 gives you the Windows `.exe` or macOS `.app` build, your job is to audit it specifically for desktop usage.

### Readability (The PDF Viewer)
- Mobile PDFs are often zoomed in. On a 24" monitor, a PDF can look stretched or tiny.
- **Audit task:** Check if the text is comfortable to read. Ensure the watermark overlay (email + ID) does not obstruct critical diagrams on large screens.
- Recommend dark mode toggles for late-night desktop studying.

### Mouse & Hover States
- Mobile is built for touch. Desktop is built for mice.
- **Audit task:** Verify that buttons, exam options, and navigation items have clear **hover states** (e.g., they change color slightly when the mouse is over them). If they don't, add them to your Figma v2 change list for Person 2.

### Keyboard Navigation
- Power users on desktop expect to navigate quickly with a keyboard.
- **Audit task:** During exams, can a student select option A, B, C, or D using the keyboard? Can they use the arrow keys to go to the Next or Previous question? If not, request these shortcuts from Person 2.

## 2. Store Assets for Desktop

You are responsible for the App Store and Play Store screenshots.
If we distribute the macOS app via the Mac App Store or the Windows app via the Microsoft Store:
- **Task:** Capture high-resolution screenshots of the Desktop layout (wide aspect ratio).
- Highlight desktop-specific features in the marketing copy (e.g., "Study comfortably on your PC with our side-by-side exam view!").

## 3. Content Preparation for Large Screens

- **Images:** If you have MCQ diagrams, ensure you export them in high enough resolution (up to 1600px width) so they do not look blurry on a 4K monitor.
- **PDF Scans:** If you are scanning past papers, ensure the DPI is high enough (150-300 DPI) so the text remains crisp when expanded on a large screen.
